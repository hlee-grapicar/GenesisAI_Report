# Genesis OSC Bridge 실행 프로그램

**Genesis OSC Bridge**는 언리얼 엔진 5(Unreal Engine 5)와 파이썬 기반의 물리 시뮬레이터인 **Genesis** 간의 양방향 실시간 물리 환경 동기화를 지원하는 통신(OSC) 플러그인입니다.

본 패키지는 파이썬 설치나 복잡한 환경 구성 없이, 동봉된 **`.exe` 실행 파일**을 켜는 것만으로 언리얼 엔진과 연동되는 고성능 물리 시뮬레이션 환경을 즉시 구축할 수 있도록 독립 실행형으로 빌드되었습니다.

---

## 시작 가이드

### 1. 언리얼 엔진 환경 세팅
1. **플러그인 활성화**: 언리얼 프로젝트에 `GenesisOSCBridge` 플러그인 소스를 복사하고 적용합니다.
2. **액터 배치**: 레벨(맵) 화면에 `GenesisOSCBridge` 액터를 배치합니다.
3. **타겟 액터 지정**: 제네시스 시뮬레이터 내부 물리 객체의 연산 결과(좌표/회전)를 실시간으로 넘겨받을 대상 액터를 디테일 패널의 `TargetActor` 변수에 할당합니다.
4. **장애물 태그 설정**: 제네시스 환경과 동기화할 언리얼 레벨 내 장애물(액터 또는 충돌체 컴포넌트)을 선택한 뒤, 디테일 패널의 **Tags(태그)** 항목에 `GenesisObstacle`을 추가합니다. (기본 콜리전 컴포넌트(Box, Sphere, Capsule)가 있는 경우 해당 치수를 그대로 사용하며, 없는 일반 StaticMesh의 경우 바운딩 박스 크기를 추출해 기본 도형으로 대체합니다.)

### 2. 시뮬레이터 실행 순서
1. 동봉된 **`GenesisOscServer.exe`** 실행 파일을 더블클릭하여 단독 실행합니다.
2. 커맨드 창에 `[OSC] Manager Started`라는 연결 대기 메시지가 뜨면, 언리얼 엔진에서 **Play(플레이)** 버튼을 클릭합니다.
3. 언리얼 엔진은 시작과 동시에 레벨 장애물 및 초기 물리 환경 데이터를 시뮬레이터(실행 파일)로 자동 전송합니다. 시뮬레이터는 이를 바탕으로 자체 물리 씬(Scene)을 완벽하게 구성하고 연산을 시작합니다.
4. 이후 언리얼의 뷰포트에 있는 타겟 액터가 시뮬레이터 내부 물리 법칙 결과에 따라 실시간으로 연동되어 똑같이 작동합니다.

## 커맨드라인 옵션 (고급 설정)
시뮬레이터(`.exe`)를 명령 프롬프트나 바로가기 매개변수로 실행할 때, 다음과 같은 포트 및 디버그 환경 변수 설정을 지원합니다.
* `--send_ip <IP주소>` : 언리얼 엔진이 구동 중인 PC의 호스트 IP 지정 (기본값: `127.0.0.1`)
* `--recv_port <포트>` : 언리얼 엔진으로부터 전체 제어 데이터를 수신할 로컬 포트 (기본값: `7001`)
* `--send_port <포트>` : 언리얼 엔진으로 위치/회전 상태 정보를 송신할 포트 (기본값: `7002`)
* `--send_port_obs <포트>` : 언리얼 엔진으로 옵저베이션(관측) 정보를 송신할 포트 (기본값: `7004`)
* `--cpu` : 시뮬레이터를 GPU 가속 대신 순수 CPU 연산으로 강제 전환
* `--headless` : 시뮬레이터 자체의 3D 시각화 창을 띄우지 않고 백그라운드 연산만 수행 (언리얼과 100% 연동 시 창 없이 사용하는 것을 권장)
* `-v` 또는 `--verbose` : 수신되는 서버 로그 및 내부 연산 결과를 터미널 창에 상세 출력

**실행 매개변수 적용 예시:**
```cmd
GenesisOscServer.exe --send_ip 192.168.0.10 --cpu --headless -v
```

## 핵심 통신 및 상호작용 기능

언리얼 엔진의 블루프린트나 C++ 코드를 통해 제네시스 시뮬레이터와 양방향으로 실시간 데이터를 주고받습니다.

### 1. 물리 환경 자동 스캐닝 및 동기화 (`/Init/`)
* **`GatherLevelObstacles()`**: 언리얼 레벨에 자유롭게 배치된 `GenesisObstacle` 태그 액터들의 콜리전 치수와 트랜스폼 값을 분석하여 시뮬레이터로 수집/전송합니다. (박스, 구, 실린더, 평면 기본 지원)
* **`SendInitPhysics()`**: 중력, 물리 업데이트 사이클(TimeStep), 기본 마찰력 등을 시뮬레이터에 보내 기초 환경을 통일시킵니다.

### 2. 동적 벡터 제어 및 힘 적용 (`SendForce`)
* 언리얼 엔진에서 블루프린트의 `SendForce(X, Y, 대 Z)` 노드를 호출하면, 제네시스 시뮬레이터 내에서 상호작용 중인 타겟 객체에 지정된 방향으로 물리적인 힘(Force / Impulse)이 가해집니다. 이를 통해 플레이어의 입력이나 충돌에 대응하여 객체를 원하는 대로 제어할 수 있습니다.

### 3. 실시간 상태 전송 및 원격 리모컨
* **상태 동기화**: 제네시스는 내부 물리 루프를 통해 타겟 객체의 최신 좌표와 쿼터니언(회전값)을 고속으로 언리얼 엔진으로 쏘아줍니다. 언리얼은 `7002`번 수신 채널을 통해 이 데이터를 가공하여 실제 오브젝트를 이질감 없이 동기화시킵니다.
* **명령 제어 (`SendCommand`)**: 블루프린트에서 `Start`, `Stop`, `Reset`, `Pause` 명령을 패킷으로 넘기면 물리 시뮬레이션을 중지하거나, 오브젝트를 원래의 시작 지점으로 원격 리셋시킬 수 있습니다.
